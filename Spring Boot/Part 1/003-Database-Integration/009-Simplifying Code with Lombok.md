## Lombok Dependency (`pom.xml`)

```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <scope>annotationProcessor</scope>
</dependency>
```

### Why this dependency is added

- Adds the Lombok library to the project.
- Generates boilerplate code (getters, setters, constructors, etc.) during compilation.
- Reduces the amount of manual code you need to write.
- `annotationProcessor` ensures Lombok runs only during compilation and is not included in the final application.

## Lombok Entity (`User.java`)

```java
package com.database.settingspringdatajpa.entities;

import jakarta.persistence.*;
import lombok.Getter;
import lombok.Setter;

@Setter
@Getter
@Entity
@Table(name = "users")
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "id")
    private Long id;

    @Column(nullable = false, name = "name")
    private String username;

    @Column(nullable = false, name = "email")
    private String email;

    @Column(nullable = false, name = "password")
    private String password;

}
```

### Why this is written this way

- `@Setter` – Automatically generates setter methods for all fields, so you don't have to write them manually.
- `@Getter` – Automatically generates getter methods for all fields.

To add this annotation we simply move the cursor to `User` then press `Alt + Enter` then select `Lombok Getter and Setter`

---

## Main Class

```java
package com.database.settingspringdatajpa;

import com.database.settingspringdatajpa.entities.User;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SettingSpringDataJpaApplication {

    public static void main(String[] args) {
//        SpringApplication.run(SettingSpringDataJpaApplication.class, args);

        var user = new User();
        user.setUsername("admin");
        user.setPassword("admin");
    }

}
```

### Why this is written this way

- `var user = new User();` – Creates a new `User` object. The `var` keyword lets Java infer the variable type (`User`).
- `user.setUsername("admin");` – Calls the setter generated by Lombok to assign the username.
- `user.setPassword("admin");` – Calls the setter generated by Lombok to assign the password.
- `SpringApplication.run(...)` is commented out because this example only demonstrates that Lombok-generated setter methods can be used without writing them manually.

# Second approach

## Entity Class (`User.java`)

```java
package com.database.settingspringdatajpa.entities;

import jakarta.persistence.*;
import lombok.AllArgsConstructor;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

@Setter
@Getter
@AllArgsConstructor
@NoArgsConstructor
@Entity
@Table(name = "users")
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "id")
    private Long id;

    @Column(nullable = false, name = "name")
    private String username;

    @Column(nullable = false, name = "email")
    private String email;

    @Column(nullable = false, name = "password")
    private String password;

}
```

---

### `@AllArgsConstructor`

```java
@AllArgsConstructor
```

**Why it was added:**
Automatically generates a constructor with parameters for all fields in the class.

Generated constructor:

```java
public User(Long id, String username, String email, String password)
```

**Advantage:**

- Initializes all fields in a single line.
- Eliminates the need to call multiple setter methods.
- Makes object creation cleaner and more concise.

---

### `@NoArgsConstructor`

```java
@NoArgsConstructor
```

**Why it was added:**
Automatically generates a constructor with no parameters.

Generated constructor:

```java
public User() {
}
```

**Advantage:**

- Required by JPA/Hibernate to create entity objects.
- Allows creating an empty object and setting values later using setters.

---

---

### Object Creation

**Before**

```java
var user = new User();
user.setUsername("admin");
user.setEmail("admin@gmail.com");

```

**After**

```java
var user = new User(1L, "admin", "admin@gmail.com", "admin");
```

**Advantage:**

- Creates and initializes the object in a single statement.
- Reduces boilerplate code.
- Improves readability when all field values are known at the time of object creation.

# Third approach: Builder annotation

## Entity Class (`User.java`)

```java
package com.database.settingspringdatajpa.entities;

import jakarta.persistence.*;
import lombok.*;

@Setter
@Getter
@AllArgsConstructor
@NoArgsConstructor
@Builder
@Entity
@Table(name = "users")
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "id")
    private Long id;

    @Column(nullable = false, name = "name")
    private String username;

    @Column(nullable = false, name = "email")
    private String email;

    @Column(nullable = false, name = "password")
    private String password;

}
```

---

### `@Builder`

```java
@Builder
```

**Why it was added:**
Automatically generates a **Builder** for the `User` class, allowing objects to be created using a fluent, readable syntax instead of constructors or multiple setter methods.

**Advantage:**

- Improves code readability.
- Allows setting only the required fields.
- Eliminates the need to remember constructor parameter order.
- Makes object creation easier for classes with many fields.
- Reduces the risk of passing values to the wrong constructor parameter.

---

## Main Class

```java
package com.database.settingspringdatajpa;

import com.database.settingspringdatajpa.entities.User;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SettingSpringDataJpaApplication {

    public static void main(String[] args) {
//        SpringApplication.run(SettingSpringDataJpaApplication.class, args);

        var user = User.builder()
                .username("admin")
                .password("admin")
                .email("admin@gmail.com")
                .build();

    }

}
```

---

### Object Creation Using Builder

**Before**

```java
var user = new User(1L, "admin", "admin@gmail.com", "admin");
```

**After**

```java
var user = User.builder()
        .username("admin")
        .password("admin")
        .email("admin@gmail.com")
        .build();
```

**Advantage:**

- Each field is assigned by its name, making the code self-explanatory.
- Field values can be provided in any order.
- Only the desired fields need to be specified.
- The `build()` method creates and returns the completed `User` object.
