# Population Vs Sample Data

Here's a simple comparison of **Population** and **Sample** in tabular form.

| **Aspect**          | **Population**                                                           | **Sample**                                              |
| ------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| **Definition**      | The complete set of all individuals, items, or observations of interest. | A subset of the population selected for study.          |
| **Size**            | Usually very large or may include every member.                          | Smaller than the population.                            |
| **Representation**  | Represents the entire group.                                             | Represents only a portion of the group.                 |
| **Purpose**         | Used to describe all members of a group.                                 | Used to draw conclusions about the population.          |
| **Data Collection** | More time-consuming and expensive.                                       | Faster and less expensive.                              |
| **Accuracy**        | Provides the true value (parameter).                                     | Provides an estimate (statistic).                       |
| **Notation**        | Population size = **N**                                                  | Sample size = **n**                                     |
| **Measures**        | Mean (μ), Standard Deviation (σ), Variance (σ²)                          | Mean ((\bar{x})), Standard Deviation (s), Variance (s²) |
| **Example**         | All 5,000 students in a university.                                      | 300 students selected from the university.              |

### Example

| **Population**                                | **Sample**                                 |
| --------------------------------------------- | ------------------------------------------ |
| All employees of a company (2,000 employees). | 200 employees selected for a survey.       |
| Every voter in a country.                     | 1,500 voters chosen for an opinion poll.   |
| All patients in a hospital.                   | 100 patients selected for a medical study. |
| All books in a library.                       | 250 books selected for catalog analysis.   |

### Key Difference

- **Population** = **Entire group** you want to study.
- **Sample** = **Part of the population** used to make inferences about the entire group.
