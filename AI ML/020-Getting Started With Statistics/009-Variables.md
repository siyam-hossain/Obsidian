# What are Variables?

## Definition

A **variable** is a characteristic or property of an individual, object, or observation that can take different values.

### Examples of Statistical Variables

- Age
- Height
- Weight
- Gender
- Blood Group
- Income
- Temperature

> A variable can have different values for different individuals.

---

## Python vs Statistics

```python
# Python variables
age = 25

ages = [18, 21, 19, 22, 20]
```

In statistics:

- **Age** is the **variable**.
- **25** is one **observation (value)** of that variable.
- **[18, 21, 19, 22, 20]** is a **dataset** containing multiple observations of the variable **Age**.

---

# Types of Variables

Variables are mainly classified into two categories:

1. Quantitative (Numerical)
2. Qualitative (Categorical)

```text
Variables
├── Quantitative (Numerical)
│   ├── Discrete
│   └── Continuous
│
└── Qualitative (Categorical)
    ├── Nominal
    └── Ordinal
```

---

# 1. Quantitative Variables

A **quantitative variable** represents numerical values that can be measured or counted.

### Types

## a) Discrete Variable

A discrete variable can take only **countable whole-number values**.

### Examples

- Number of students
- Number of cars
- Number of books
- Number of children

Possible values:

$$
0,\;1,\;2,\;3,\;\ldots
$$

---

## b) Continuous Variable

A continuous variable can take **any value within a given range**, including decimal values.

### Examples

- Height
- Weight
- Temperature
- Time
- Distance

Possible values:

$$
165.2,\;165.25,\;165.253,\ldots
$$

---

# 2. Qualitative (Categorical) Variables

A **qualitative variable** describes categories or qualities instead of numerical measurements.

### Types

## a) Nominal

Categories have **no natural order**.

Examples:

- Gender
- Blood Group
- Nationality
- Eye Color

---

## b) Ordinal

Categories have a **meaningful order**, but the differences between categories are not measurable.

Examples:

- Education Level
- Satisfaction Rating
- T-shirt Size

Example:

```text
Small < Medium < Large
```

or

```text
Poor < Fair < Good < Excellent
```

---

# Summary

| Type       | Description              | Examples                      |
| ---------- | ------------------------ | ----------------------------- |
| Discrete   | Countable numbers        | Number of students            |
| Continuous | Measurable values        | Height, Weight                |
| Nominal    | Categories without order | Blood Group, Gender           |
| Ordinal    | Categories with order    | Education Level, Satisfaction |
