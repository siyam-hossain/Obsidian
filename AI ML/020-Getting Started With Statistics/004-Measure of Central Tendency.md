# Measure of Central Tendency

1. Mean
2. Median
3. Mode

| Measure    | Population Formula                                                                                                             | Sample Formula                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **Mean**   | $\mu = \dfrac{\sum_{i=1}^{N} x_i}{N}$                                                                                          | $\bar{x} = \dfrac{\sum_{i=1}^{n} x_i}{n}$                                                                                      |
| **Median** | Arrange all $N$ observations in ascending order. If $N$ is odd: Middle value. If $N$ is even: $\dfrac{x_{N/2} + x_{N/2+1}}{2}$ | Arrange all $n$ observations in ascending order. If $n$ is odd: Middle value. If $n$ is even: $\dfrac{x_{n/2} + x_{n/2+1}}{2}$ |
| **Mode**   | Value that occurs most frequently in the entire population.                                                                    | Value that occurs most frequently in the sample.                                                                               |

## Symbols

| Symbol    | Meaning                 |
| --------- | ----------------------- |
| $\mu$     | Population mean         |
| $\bar{x}$ | Sample mean             |
| $x_i$     | Individual observation  |
| $N$       | Population size         |
| $n$       | Sample size             |
| $\sum$    | Sum of all observations |
