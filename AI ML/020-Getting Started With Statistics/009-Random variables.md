# What are Random Variables?

## Definition

A **random variable** is a variable whose value is determined by the outcome of a random experiment.

It assigns a **numerical value** to each possible outcome of a random process.

> A random variable is usually denoted by capital letters such as **X**, **Y**, or **Z**.

---

## Examples

### Example 1: Tossing a Coin

Experiment:

Toss a coin once.
Define the random variable:

$$
X =
\begin{cases}
1, & \text{if Heads} \\
0, & \text{if Tails}
\end{cases}
$$

Possible values of $X$:

$$
\{0, 1\}
$$

---

### Example 2: Rolling a Die

Experiment:

Roll a six-sided die.

Let

$$
X = \text{Number shown on the die}
$$

Possible values:

$$
\{1,2,3,4,5,6\}
$$

---

### Example 3: Number of Customers

Suppose we count the number of customers entering a store in one hour.

Let

$$
X = \text{Number of customers}
$$

Possible values:

$$
0,\;1,\;2,\;3,\;\ldots
$$

---

# Types of Random Variables

Random variables are divided into two types:

```text
Random Variable
├── Discrete Random Variable
└── Continuous Random Variable
```

---

## 1. Discrete Random Variable

A **discrete random variable** takes a **countable** number of values.

### Examples

- Number of heads in three coin tosses
- Number on a die
- Number of students absent
- Number of phone calls received

Example:

Toss a coin three times.

Let

$$
X = \text{Number of Heads}
$$

Possible values:

$$
\{0,1,2,3\}
$$

---

## 2. Continuous Random Variable

A **continuous random variable** can take **any value within an interval**.

### Examples

- Height of a student
- Weight of a person
- Temperature
- Time required to finish a task
- Daily rainfall

Possible values:

$$
150.2,\;150.25,\;150.251,\ldots
$$

---

# Variable vs Random Variable

| Variable                                 | Random Variable                                          |
| ---------------------------------------- | -------------------------------------------------------- |
| Represents a characteristic or property. | Represents the numerical outcome of a random experiment. |
| May or may not involve chance.           | Always depends on chance or randomness.                  |
| Example: Height, Age, Gender             | Example: Number of heads, Dice value, Waiting time       |

---

# Key Points

- A random variable assigns **numbers** to the outcomes of a random experiment.
- It is represented by **capital letters** such as **X**, **Y**, or **Z**.
- Each observed value of a random variable is called a **realization** or **observation**.
- Random variables are classified as **Discrete** or **Continuous**.
