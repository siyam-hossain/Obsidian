# Dart control flow statement

The control statements or control statements are used to control the flow of Dart program. In dart, Control flow statement can be categorized mainly in three following ways.

1. Decision making statements
2. Looping statements
3. Jump statements

# Dart decision making statements

The decision making statements allow use to determine which statement to execute based on the test expression at runtime. dart provides following types of Decision-making statement.

1. If statement
2. If-else statement
3. If else if statement
4. Switch case statement

# Dart looping statements

Dart loop is used to run a block of code repetitively for a given number of times or until matches the specified condition.

1. Dart for loop
2. Dart for...in loop
3. Dart while loop
4. Dart do-while loop
