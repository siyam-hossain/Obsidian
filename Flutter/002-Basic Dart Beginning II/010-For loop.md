# Dart For loop

The for loop is used when we know how many times a block of code will execute.

```dart
void main() {

  for(var i = 0; i < 10; i++){
    print("hello world $i");
  }

}
```

```output
hello world 0
hello world 1
hello world 2
hello world 3
hello world 4
hello world 5
hello world 6
hello world 7
hello world 8
hello world 9
```
