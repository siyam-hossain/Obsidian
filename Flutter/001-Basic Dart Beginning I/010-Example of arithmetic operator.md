# Dart Operators

Arithmetic operators

```dart
void main() {
  var n1 = 16;
  var n2 = 5;

  print("n1 + n2 = ${n1 + n2}");
  print("n1 - n2 = ${n1 - n2}");
  print("n1 x n2 = ${n1 * n2}");
  print("n1 / n2 = ${n1 / n2}");
  print("true division = ${n1 ~/ n2}");
  print("n1 % n2 = ${n1 % n2}");
}
```

```output
n1 + n2 = 21
n1 - n2 = 11
n1 x n2 = 80
n1 / n2 = 3.2
true division = 3
n1 % n2 = 1
```
