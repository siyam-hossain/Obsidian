# Dart Number

#### Integer

Integer values represent the whole number or non-fractional values.

#### Double

Double value represents the floating number or number with the large decimal points.

---

```dart
void main(){
  var x = 10;
  var y = 23.65;

  print(x);
  print("type of data: ${x.runtimeType}");
  print(y);
  print("type of data: ${y.runtimeType}");
}
```

```output
10
type of data: int
23.65
type of data: double
```
